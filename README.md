# Creations by Roma Apuyan

Official photography and videography website and booking portal for https://creationsbyromaapuyan.studio/.

## Applications
- `index.html` — official homepage, services and portfolio.
- `booking.html` — customer registration, service requests, booking history.
- `admin.html` — studio management for authorized Super Administrators.
- `email-confirmed.html` — Supabase signup verification page.
- `download.html` — official app download placeholders.
- `drive-image-test.html` — test for Google Drive public-photo embedding.
- `assets/css/roma-app.css` — shared responsive dashboard styling.
- `assets/js/` — frontend integration with Supabase and Google Drive.

Hosting: Cloudflare Pages via the GitHub `main` branch. No build command; output directory `.`.
Backend: existing Supabase project (database SQL is supplied in the separate complete project package, not this public website ZIP).
